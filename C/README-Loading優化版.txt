全好蔬果｜Loading 動畫優化版

本次修改：
1. 全站頁面進入時顯示「資料載入中」遮罩，頁面與首批 API 請求完成後自動關閉。
2. 點選站內導覽連結時立即顯示「頁面切換中」。
3. Supabase / Cloudflare Workers API 請求統一顯示載入狀態。
4. POST / PUT / PATCH 類型請求顯示「儲存中」動態點點；DELETE 類型顯示「刪除中」。
5. Loading 狀態具備延遲顯示及請求計數，避免多個請求交錯時提早消失。
6. 員工管理頁面已納入相同的初始載入與 API Loading 機制。

部署方式：
將 phase6work 資料夾內的檔案依原有結構部署至 Cloudflare Pages（Direct Upload）。
請先在測試環境驗證管理者、員工、店家登入，以及報價新增/修改/刪除流程。

注意：
此版本僅調整前端 Loading 顯示與請求狀態管理；未更動 Supabase schema、資料表、RLS 或 Worker API 權限。


【本次調整】
- 頁面切換不顯示全頁 Loading 遮罩。
- 不會只因進入頁面就顯示全頁遮罩。
- 實際發生 Supabase / Workers 資料讀取、儲存、刪除請求時，仍會顯示對應 Loading。


【依使用者最新要求調整】
- 全站完全隱藏中央全畫面「資料載入中」遮罩、轉圈圖示及底部進度條。
- 即使既有程式在資料請求期間呼叫顯示遮罩，也不會再覆蓋整個頁面。
- 不修改 Supabase 資料操作、登入及角色權限邏輯。

【讀取圖示統一調整】
- 員工管理列表的「載入中」已加入與店家聯絡人視窗相同的旋轉圓形圖示及動態點點。
- 保留局部讀取提示，不顯示全畫面遮罩。

【員工管理讀取圖示修正】
- 員工列表讀取狀態改用內嵌 SVG 旋轉圖示，避免 CSS 樣式繼承導致圖示不顯示。
- 初始載入及重新整理員工列表時均顯示圖示與動態點點。

【返回首頁閃現登入頁修正】
- 首頁先確認 Supabase 登入狀態，再顯示登入頁或角色工作首頁。
- 已登入使用者返回首頁時，避免短暫看到登入表單。
- 若未登入、登入狀態讀取失敗或需要重新登入，仍會正常顯示登入頁。

【店家管理與員工管理版面統一】
- 統一頂部導覽列置中寬度、Logo/標題位置與高度。
- 統一主要內容最大寬度、上下留白、標題字級與卡片外觀。
- 統一表格字級、儲存格間距、表頭底色及按鈕圓角。
- 保留兩頁原有功能、欄位、按鈕事件及權限邏輯。

【員工管理搜尋與批次功能】
- 新增員工姓名、Email、手機搜尋，輸入時即時篩選。
- 新增全選／取消全選，目前全選僅作用於搜尋後顯示的員工。
- 新增批次啟用、批次停用及批次軟刪除。
- 批次刪除使用既有員工軟刪除 API，保留歷史報價與操作紀錄。
- 批次作業逐筆呼叫既有 API，完成後回報成功／失敗數量。
- 店家管理頁既有搜尋與批次功能維持不變。
